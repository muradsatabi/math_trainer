# Банк шаблонов

Канонические материалы приложения находятся только в `templates/*.json`. Сгенерированные экземпляры существуют в снимках занятий в браузере, а не как редактируемый постоянный банк. Тот же генератор используется практикой и PDF.

* common_factor.json — численный и буквенный общий множитель.
* numeric_bracket_multiplication.json — числовой множитель на скобку.
* literal_bracket_multiplication.json — буквенный множитель на скобку.

Рабочие, отложенные и требующие проверки записи различаются статусом. В практику и PDF попадают только активные материалы. В импортированных темах сохранены исходные условия, относительный путь и SHA-256 методического источника. Номера ID не устанавливают граф зависимостей или ранг трудности.

Прежние manifest/blocks/skills/sources и импорт постоянного банка удалены по поручению владельца. История Git сохраняет старые версии; пользовательские снимки занятий остаются совместимыми через модели сериализации.
