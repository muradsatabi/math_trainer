# Шрифты приложения

Carlito используется для интерфейса, Caladea — для математических выражений.
Оба семейства распространяются по SIL Open Font License 1.1.
Тексты лицензий с уведомлениями авторов сохранены рядом с файлами.

Источники загрузки 16 октября 2026 года:

- https://github.com/google/fonts/tree/main/ofl/carlito
- https://github.com/google/fonts/tree/main/ofl/caladea

Файлы не модифицировались. Запросов к Google Fonts во время работы приложения нет.
Прежние Windows-шрифты заменены с согласия владельца перед публичной публикацией.
