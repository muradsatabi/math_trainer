# Публикация Flutter Web через GitHub Pages

Адрес сайта: https://muradsatabi.github.io/math_trainer/
Опубликован 16 октября 2026 года. HTTPS-страница, main.dart.js, банк и шрифт проверены: HTTP 200.

## Подготовка

Владелец разрешил публикацию, замену Windows-шрифтов свободными и очистку
истории с резервной копией. Используются Carlito и Caladea, лицензии SIL OFL
включены в ресурсы. Локальная резервная копия исходной истории и шрифтов:
.dart_tool/publication-backup-20261016/. Она исключена из Git и публикации.
Источник ограничений старых шрифтов: https://learn.microsoft.com/en-us/typography/fonts/font-faq#web

## Настроенная последовательность сборки

Файл .github/workflows/pages.yml опубликован в main. При изменениях main
он устанавливает Flutter 3.47.6, получает зависимости, запускает analyze и тесты,
затем собирает Web с --base-href /math_trainer/ и публикует только build/web.
Ошибка проверки или сборки предотвращает новую публикацию.
Для Pages включён источник GitHub Actions. Репозиторий публичный.
В GitHub Free репозиторий должен быть публичным.

Отдельные ключи для сборки не нужны: публикация использует временный GITHUB_TOKEN
с правами pages: write и id-token: write только в задании deploy.
Новые версии публикуются после принятых изменений в main; можно запустить workflow вручную.

## Проверка после включения

Первый запуск Actions успешно выполнил анализ, тесты, сборку и публикацию.
Проверены HTTPS-страница,
загрузка main.dart.js и банка по адресу /math_trainer/assets/bank/manifest.json.
Визуальная проверка опубликованной версии и прохождение с другого устройства
пока не подтверждены. Инструмент компьютерного управления остановил проверку
Edge, так как не смог надёжно определить URL для соблюдения политики доступа.
Локальная сборка и тесты не подтверждают успешную публикацию.

Сайт доступен независимо от ноутбука разработчика. Это статическое приложение;
оно не сохраняет результаты на сервере. Встроенный банк доступен посетителям.
Настройка Pages не добавляет общие аккаунты или синхронизацию прогресса.
