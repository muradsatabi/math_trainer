## Что нужно уточнить перед использованием в маршруте

1. **Значение узла.** В схеме смешаны действия («сокращение дробей»), понятия («несократимая дробь»), широкие области («обыкновенная дробь — ядро») и пояснение связи. Не каждый прямоугольник уже является одним микроумением или одним шаблоном задания.
2. **Значение стрелки.** В файле нет подписей, разделяющих обязательную основу, рекомендуемую учебную последовательность, поясняющую связь и возврат при затруднении. Направления извлечены как source → target; их педагогический смысл требует утверждения.
3. **Несколько основ.** При нескольких входящих стрелках нужно определить, необходимы ли все основы или допускаются альтернативные способы. Нельзя вывести это из рисунка автоматически.
4. **Освоение.** Для каждого используемого в маршруте микроумения нужны утверждённые диагностические задания и критерии освоения. Граф не содержит порогов или правил оценивания.
5. **Разные уровни.** Каталог предметов, глав и разделов хранится отдельно. Родственные действия в числовом и буквенном представлении можно связать, сохраняя разные задания и критерии. Не все такие связи обязаны блокировать переход.

В частности, наличие стрелок от свойств НОД или НОК ещё не означает обязательного прохождения соответствующей темы перед любым действием с дробями. Это вопрос методики, а не вывод технического импорта.

## Предлагаемая карточка для обсуждения узла

| Поле рабочего решения | Что фиксируем |
| --- | --- |
| Ссылка на источник | ID элемента Draw.io и название; при детализации — исходный родительский узел |
| Уровень | Тема, понятие, микроумение или пояснение |
| Проверяемое действие | Что именно ученик должен уметь выполнить |
| Задания | Ссылки на утверждённые ID единого банка, без копирования содержания |
| Основы | Какие умения нужны, обязательность, правило «все» или альтернативы |
| Возврат | Куда направлять при конкретном подтверждённом затруднении |
| Освоение | Утверждённый способ подтверждения; до согласования — «не определено» |
| Статус | Идея, предложено или утверждено; ссылка на решение владельца |

Это рабочая форма обсуждения, не окончательная схема данных банка. Случайные ID Draw.io сохраняются для прослеживаемости; назначение устойчивых ID умений и сопоставление с ними нужно согласовать отдельно. Геометрия и цвет не участвуют в определении зависимостей.

## Проверки будущего утверждённого графа

После согласования формата следует проверять уникальность ID, существование концов связей, тип и направление связей, ссылки на банк и версию методического решения. Обязательные предпосылки не должны образовывать цикл, который делает освоение недостижимым; связи возврата рассматриваются отдельно и могут возвращать ученика к уже посещённым узлам. Проверка структуры не подтверждает педагогическую корректность.

## Первый рабочий участок

Вынесение общего множителя отсутствует в этой схеме. Для него нужно предложить отдельный фрагмент числовых и буквенных микроумений и связать его с уже существующими основами только после методического утверждения. НОД не назначается обязательной основой автоматически: в переданном блоке на одинаковый числовой коэффициент наибольший множитель не требуется. Содержание этого блока не расширяется новыми заданиями при систематизации графа.
