## Исправление: форма записи конструктора — 10 октября 2026 года

По замечанию владельца устранена ошибка: доступность проверки зависела от совпадения с четырьмя демонстрационными записями. Это противоречило требованию разрешать полные неверные ответы.

* Проверка формы отделена от правильности. Пустая запись, незакрытые/лишние скобки, пустые скобки, отсутствующий операнд и недопустимый символ блокируют проверку. Числа, буквы, вложенные скобки, действия и неявное умножение поддерживаются без сравнения с образцом.
* Любой полный неверный ответ, например 3(2x + 4), допускается к проверке. После отправки показаны красное состояние, «Пока не получилось!», помощь и «Дальше»; редактирование блокируется.
* Для ответов вне трёх известных ошибочных примеров используется общий разбор без выдуманной классификации ошибки. Для известных примеров сохранены конкретные объяснения.
* Правило уточнено в docs/product_requirements.md, описание демонстрации — в README.md. Общая проверка эквивалентности остаётся отложенной; текущий образец верного ответа — 3(2x + 3).
