# Генератор заданий в PDF

## Свободные числа и фильтры усложнений — 3 ноября 2026 года

Замечания первоначально были зафиксированы без реализации; после последующей прямой команды владельца оба изменения реализованы и 3 ноября опубликованы на основном сайте https://muradsatabi.github.io/math_trainer/. Публикация подтверждена успешным GitHub Actions и совпадением опубликованного файла приложения с проверенной сборкой; подробности — в development_status.md.

**Свободные числа.** В PDF для буквенного общего множителя с числовым остатком внутри скобок теперь варьируется число от 1 до 9, например `ab + 3a → a(b + 3)`. Это технический диапазон текущей реализации, а не общий методический норматив. Единица остаётся одним из возможных значений. Во всех исходных слагаемых общая буква сохранена: свободное число появляется после вынесения множителя, а не вместо него в исходном выражении. Найденная причина прежних единиц — фиксированная запись `1` в генераторе; появление исходного числового слагаемого без общей буквы не подтвердилось. Математическое равенство проверено для исходного шаблона и всех его рабочих сочетаний.

В форме PDF название «Остаток — единица» заменено на «Свободное число в скобках», показан пример с 3; названия соответствующих сочетаний также обновлены. Канонический JSON шаблонов, его утверждение, сохранённые занятия и прежнее поведение генерации практики не меняются. Расширение действует через опцию PDF-генерации `varyLiteralConstants`; числовой общий множитель с остатком 1 не изменён. Обычные задания, тесты и все варианты работ используют новое правило PDF.

**Разрешённые усложнения.** Справа от шести уровней показаны чекбоксы; на ширине области менее 700 px — под уровнями. По умолчанию все доступные признаки разрешены. Для выбранной темы показываются только признаки её рабочих шаблонов. Доступны степени, вычитание, другой порядок множителей, три слагаемых, число в скобках без букв, разные коэффициенты, две оставшиеся буквы и скобки в слагаемом — в зависимости от темы.

Снятая галочка исключает все отдельные шаблоны и сочетания с этим признаком из списка, подсчёта и экспорта. «Степени» объединяет степени оставшихся букв и выделение общей буквы из степени (`powers` и `factor_power`). Фильтры работают совместно с выбранными уровнями и не сбрасывают их. При повторном разрешении признака восстанавливаются выбор и индивидуальные количества скрытых шаблонов; «Выбрать все», «Снять выбор» и применение общего количества действуют только на видимые строки. При отключении всех усложнений остаётся исходный шаблон, если выбран уровень 1. В темах с плоским списком без назначенных усложнений эти фильтры и уровни не добавляются автоматически.

## Общие правила для всех тем — утверждено 1 ноября 2026 года

По прямому решению владельца описанная здесь логика PDF-генератора является общей для всех действующих и будущих математических тем, пока владелец явно не укажет обратное. При подключении новой темы эти правила применяются по умолчанию без отдельного повторного согласования. Исключение фиксируется в этом документе с указанием темы, изменяемого правила, даты и решения владельца; остальные общие правила сохраняются. Само это решение не означает, что новые темы уже реализованы.

| Шаблоны | Рабочие шаблоны выбранного уровня; отложенные в генерации не участвуют |

### Общее поведение

* При входе из конкретной темы не показывать лишний блок «Какие шаблоны использовать» и плашку уже выбранной темы. Список конкретных шаблонов и выбор уровней сохраняются. Исторический общий вход допускает выбор темы.
* Количество каждого шаблона можно менять отдельно; общее поле применяется к выбранным видимым шаблонам по кнопке «Применить к выбранным». Минус — слева, плюс — справа. Диапазон — 1–100 на шаблон, до 1000 заданий в каждом варианте.
* Порядок шаблонов можно менять стрелками и перетаскиванием, сохраняя индивидуальные количества. Доступны группировка в этом порядке, перемешивание и возрастание структурного уровня.
* Каждый вариант содержит выбранное количество заданий каждого шаблона. Для следующего варианта выражения генерируются заново; полностью одинаковые наборы исключаются даже при другой перестановке. Внутри варианта повторов нет; отдельные задания между вариантами могут повторяться.
* Все варианты формируются в одном PDF. Каждый начинается с новой страницы и имеет номер на каждой своей странице. При включении ответов сначала идут все работы, затем ответы по номерам вариантов; нумерация ответов начинается с 1 для каждого варианта. Отдельный файл ответов не создавать.
* Формат — A4 в клетку 5 мм, до 20 заданий на страницу, заполнение сверху вниз по столбцам. Для теста отводится больше места на задание: 3 задания на столбец в альбомной ориентации и 5 в книжной. На листе ученика нет ключей правильных ответов, ID шаблонов и подсказок; в тестовом формате печатаются четыре варианта ответа без выделения верного. Число столбцов применяется также к ответам и сохраняется при смене ориентации.
* В тесте у каждого задания ровно четыре ответа (А, Б, В, Г), из них ровно один верный. Неверные ответы отражают конкретные правдоподобные ошибки соответствующего умения, а не случайные изменения ради математической неверности. Правильный ответ не должен выделяться оформлением, единственным подходящим видом записи или однозначной подсказкой по длине. Порядок ответов перемешивается. Ключи в конце PDF содержат букву и верное выражение; они формируются из тех же вариантов, которые напечатаны ученику. Если подходящих проверенных вариантов недостаточно, не подменять их случайными ответами.
* Показывать число выбранных шаблонов и заданий в одном варианте; при нескольких вариантах — также число вариантов и общий объём. Пустой выбор и недопустимые количества блокируют генерацию; при ошибке доступна повторная попытка.

Конкретные математические шаблоны, допустимые параметры и сочетания определяются методикой соответствующей темы. Числа и направления усложнений общего множителя из разделов ниже не переносятся автоматически на другие темы. Структурный уровень сам по себе не является оценкой педагогической трудности.

Далее описаны текущая реализация, особенности общего множителя и история уточнений. При подключении тем руководствоваться общими правилами этого раздела и явно утверждёнными исключениями. Пробные изменения расположения PDF-кнопки на странице тем не становятся общим утверждённым оформлением.

Первоначально реализован по поручению владельца от 31 октября 2026 года в ветке `feature/template-pdf-generator` и проверялся в отдельном приватном Sites. С 2 ноября единственный основной сайт проекта — https://muradsatabi.github.io/math_trainer/. Прежние тестовые публикации не являются актуальной версией; дальнейшие обновления PDF-генератора публикуются на основном GitHub Pages. Последний подтверждённый результат публикации фиксируется в development_status.md.

## Как проверить

1. На главном экране нажать небольшую отдельную кнопку **PDF** справа от карточки общего множителя. Основная часть карточки по-прежнему открывает существующую практику.
2. Выбрать шаблоны, уровни и количество заданий для каждого. При входе из отдельной численной или буквенной темы доступны только шаблоны этой темы. Начальное значение — 5 на шаблон и в общем поле количества, начальный уровень — только 1 (уточнение владельца от 1 ноября 2026 года).
3. Выбрать порядок: группами по шаблонам, вперемешку или по возрастанию структурного уровня.
4. Нажать **Сгенерировать PDF**. Веб-версия предлагает скачать PDF средствами браузера. Специальная постоянная папка приложения не создаётся.

В форме видны число выбранных шаблонов и число заданий в одном варианте. Для нескольких вариантов дополнительно видны число вариантов и общее число заданий. Пустой запрос и неверные количества блокируют генерацию. Ограничения: 1–100 заданий на конфигурацию шаблона, не более 1000 в одном варианте; от 1 до 100 вариантов работ в одном PDF. Ошибка загрузки или экспорта отображается с возможностью повторить действие.

## Шаблоны и сочетания

Источник — `bank/templates/common_factor.json`, перенесённый из текущих методических реестров. ID и статусы сохранены: 12 числовых шаблонов (7 в работе, 5 отложены), 9 буквенных (все в работе). Отложенные показаны отдельно и в генерации не участвуют.

Уровень 1 — исходная структура; 2 — одно усложнение; 3–6 — сочетания двух–пяти рабочих направлений. Получаются 16 рабочих исходных конфигураций и 266 сочетаний: 56 числовых и 210 буквенных. Сочетания вычисляются программно, не дублируются в постоянном каталоге и не объявляются отдельно методически утверждёнными шаблонами. Число признаков не является оценкой реальной трудности.

Варьируются допустимые числа и буквы, оба остаточных коэффициента при разных коэффициентах, положение множителя и степени в соответствующих шаблонах. Общий числовой множитель выбирается из 2–12; остаточные коэффициенты — из 1–9 с необходимыми ограничениями. Буквы выбираются без повторов, кроме предусмотренного повторения общего множителя. Диапазоны — параметры первой технической пробы, не утверждённые педагогические нормы.

Генератор сохраняет заявленные признаки и тождество преобразования. Повторы выражений внутри набора исключаются. Это не утверждение о педагогической эквивалентности или реальной трудности всех сочетаний; содержательную пригодность предстоит оценить владельцу на примерах.

## PDF

Генерация полностью локальная на Dart, без ИИ, сервера и сетевой загрузки шрифтов. A4 в выбранной ориентации, клетка 5 мм, строка имени/класса/даты, до 20 выражений на страницу в обычном формате. Количество столбцов выбирается независимо от ориентации: 1, 2 или 3; по умолчанию 2 в обеих ориентациях. Порядок заполнения — сверху вниз по столбцам. Страницы ответов используют то же количество столбцов. Ключи правильных ответов, ID, названия шаблонов и подсказки в лист ученика не печатаются. При длинной записи размер формулы ограничивается шириной столбца.

Шрифты Carlito и Caladea уже включены в приложение; они встраиваются в PDF. Сгенерированные экземпляры и ответы существуют в памяти во время подготовки файла и не записываются в постоянный банк или локальную базу. Более общее решение о хранении результатов остаётся открытым.

## Проверки

Добавлены независимые проверки точного равенства многочленов для всех конфигураций, уникальности, количества, порядка, повторяемости по seed и отказа при некорректном запросе. Проверены раздельные действия карточки, мобильная/компьютерная компоновка, обе темы оформления, изменение количества, ошибка экспорта и повторная попытка. Реальное построение PDF проверяется отдельно от интерфейсного теста.

Снимки из `tool/verify_generator_render_test.dart` являются рендером Flutter-виджетов с рабочими шрифтами, а не снимками браузера. Автоматическая проверка Edge была остановлена инструментом, который не смог уверенно определить URL; фактическое браузерное скачивание остаётся для ручной проверки владельцем.

По последующему уточнению владельца восстановлено оформление карточки темы, PDF вынесен в отдельное небольшое окно справа.

## Ориентация, перенос и ответы — 31 октября 2026 года

Добавлен выбор ориентации: альбомная (по умолчанию) или книжная. Первоначально в книжной версии был один столбец, в альбомной — два; уточнение от 1 ноября 2026 года заменяет это на независимый выбор 1–3 столбцов, по умолчанию два. До 20 заданий на странице. Строки шаблонов можно перетаскивать, стрелки также сохранены. Порядок и количества передаются в PDF. Переключатель «Добавить ответы» добавляет отдельные страницы в конце того же PDF, с нумерацией в порядке заданий. Отдельный файл ответов не создаётся: пользователь отменил это предложение. Оформление страницы тем оставлено для дальнейшего обсуждения и на этом этапе не менялось.

При входе из конкретной темы заголовок «Какие шаблоны использовать» и плашка темы скрыты как избыточные (уточнение владельца от 1 ноября 2026 года). На старом общем входе переключатели тем сохраняются.

## Варианты работ — 1 ноября 2026 года

По поручению владельца добавлено количество вариантов: по умолчанию 1, от 1 до 100, с ручным вводом и кнопками минус/плюс. Во всех вариантах сохраняются выбранные шаблоны, количество заданий на каждый и режим порядка, но выражения генерируются заново. Одинаковый полный набор выражений не считается новым вариантом даже при перестановке. Отдельные выражения между вариантами могут повторяться; внутри каждого варианта повторов нет.

Все варианты скачиваются одним PDF. Каждый начинается с новой страницы и имеет номер на каждой своей странице; до 20 заданий на страницу. Если включены ответы, они идут после всех работ, с отдельными страницами и номерами вариантов; нумерация ответов начинается с 1 для каждого варианта. Например, 30 вариантов по 35 заданий дают 1050 заданий и 60 страниц работ, с ответами — 120 страниц.

## Тестовый формат — 1 ноября 2026 года

По поручению владельца добавлен выбор «Обычные задания» / «Тест — четыре ответа». По умолчанию остаются обычные задания. Оба формата используют выбранные шаблоны, уровни, количества, порядок, столбцы, ориентацию и число вариантов работ. В тесте задания нумеруются внутри каждого варианта; ответы помечены А, Б, В, Г. Вместимость тестового листа — 3 задания на столбец в альбомной ориентации и 5 в книжной. Ответы учителя при включении добавляются после всех работ и содержат номер задания, букву и верное выражение.

Для общего множителя переиспользуются две демонстрационные модели текущей практики: не разделено первое / последнее слагаемое. Третья модель PDF — ошибочная смена знака последнего слагаемого. В отличие от варианта с потерянным внешним множителем, все четыре записи сохраняют одинаковый внешний множитель и скобки. Ошибка знака оставляет альтернативу той же длины, что и правильный ответ: выбирать единственный кратчайший ответ нельзя. Все четыре ответа оформлены одним шрифтом и без выделения верного; при уменьшении блока они масштабируются совместно. Положение верного ответа перемешивается, ключи используют уже подготовленный порядок без повторного перемешивания.

Для каждого задания проверяются точная математическая верность одного ответа, неверность трёх остальных и попарное математическое различие. Неподдерживаемые или совпадающие варианты вызывают отказ генерации, случайного дополнения нет. Модели ошибок имеют демонстрационный статус; техническая проверка не заменяет их педагогическую оценку. Этот код не меняет варианты и подсказки действующей практики. Для будущих тем общий принцип сохраняется, но нужны их собственные подходящие модели ошибок.


## Пробное размещение PDF в строке состояния темы

По новому поручению владельца PDF-значок в тестовом тренажёре помещён внутрь карточки темы, справа от успешности: состояние → шкала и процент → PDF. Самостоятельное действие PDF сохраняется, нажатие не запускает практику. Название темы находится над строкой; значки, шкала и процент выровнены по общей горизонтали. Это пробный вариант для оценки, функциональность генератора PDF этим изменением не менялась.
