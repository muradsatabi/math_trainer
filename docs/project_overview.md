Математический тренажёр — описание проекта

1. Назначение

Математический тренажёр — образовательное приложение для формирования и закрепления математических навыков школьников.

Главная идея — адаптировать процесс практики к уровню конкретного ученика, помогать обнаруживать пробелы в знаниях и постепенно устранять их.

2. Основные принципы

* Обучение начинается с самых простых действий, включая нулевой уровень.
* Каждая математическая тема разбивается на небольшие последовательные этапы.
* Один этап направлен на освоение одного конкретного навыка или преодоление одной трудности.
* Сильные ученики могут быстрее переходить к сложным заданиям.
* Ученики, испытывающие затруднения, получают дополнительные промежуточные задания и объяснения.
* Ошибки ученика используются для определения его затруднений и выбора дальнейших действий.

3. Целевая аудитория

Первоначальная аудитория — ученики 8-х классов.

Первые испытания проводятся с учениками автора проекта. В дальнейшем приложение должно поддерживать другие классы и математические темы.

4. Технологии

* Язык программирования — Dart.
* Фреймворк — Flutter.
* Первоначальная платформа — Web.
* Приоритет — работа в браузере на компьютере.
* В перспективе — поддержка мобильных устройств.

Разработка ведётся в Windows, в папке D:\Dev\Projects\math_trainer.

5. Режимы приложения

В продуктовой концепции предусмотрены:

1. Диагностическое тестирование по разделу.
2. Диагностическое тестирование по теме.
3. Практика.
4. Контрольная работа по теме.
5. Контрольная работа по разделу.

На первом этапе реализуется только режим «Практика». Остальные режимы относятся к дальнейшему развитию.

6. Первая математическая тема

«Вынесение общего множителя за скобки».

Для этой темы уже разрабатывались последовательности блоков заданий, учитывающие постепенное усложнение и типичные ошибки учеников.

Банк заданий существует отдельно от программного кода приложения. Его подключение является самостоятельной задачей.

7. Первая версия приложения

Приоритет — получить работающий веб-тренажёр, в котором ученик может решать задания и получать обратную связь.

На первом этапе не требуется полноценная серверная инфраструктура или сложная система учётных записей.

Способ сохранения и передачи результатов учеников ещё предстоит уточнить.
