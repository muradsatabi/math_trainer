# Математический тренажёр

Flutter Web-прототип всех 11 экранов V3 на демонстрационных данных. Требования и фактические ограничения: [docs/development_status.md](docs/development_status.md).

## Запуск

```powershell
flutter pub get
flutter run -d web-server --web-port=5334
```

Откройте http://localhost:5334/ в браузере. Приложение использует системную светлую или тёмную тему.

Основной маршрут: первая тема → «Начать практику» → выбор ответа → «Дальше» → конструктор → закрепление → итоги → разбор ошибок. Для 6x + 9 правильный ответ — 3(2x + 3).

В конструкторе кнопка «Предыдущее задание» открывает первое проверенное задание только для просмотра. «Вернуться к текущему» сохраняет текущий ввод и результат. История доступна в основном маршруте и хранится только в памяти открытой практики.

Для просмотра отдельных демонстраций доступны параметры `?screen=start`, `task`, `constructor`, `detailed`, `recap`, `results`, `review`. Например: http://localhost:5334/?screen=detailed. В изолированном просмотре `task` кнопка «Дальше» не назначает следующее задание.

Конструктор разрешает проверять любую завершённую по форме запись из доступных символов, в том числе неправильную. Незакрытые скобки, пустые скобки и незавершённые действия блокируют проверку. Демонстрационный правильный ответ — `3(2x+3)`; принимаются также `3×(2x+3)`, `(2x+3)×3`, `(2x+3)3` и варианты явного умножения в `2x`; общая проверка эквивалентности выражений ещё не реализована. Успешность практики остаётся 0%; счётчики итогов и статусы тем демонстрационные. Реального банка, адаптивных переходов и сохранения практики пока нет.
